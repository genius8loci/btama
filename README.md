# BTama

Внутриигровой модуль для **Bloody Trapland** (XNA / .NET Framework, 32-битный
процесс). Собирается в DLL, инжектируется в процесс игры, рисует поверх неё
интерфейс ImGui через DirectX 9.

## Возможности

- ESP игроков и ловушек;
- параметры локального персонажа: скорость, высота прыжка, гравитация,
  неуязвимость, бесконечный прыжок, респавн;
- просмотр и правка флагов ловушек (`Used`, `Updateable`, `GoreStick`,
  плюс `Speed` и `CanTrigger` для классов, помеченных как `BoomTrap`).

## Управление

| Клавиша | Действие |
|---|---|
| `INSERT` | закрепить или убрать меню |
| `TAB` | показать меню на время удержания |
| `END` | снять хуки и выгрузить DLL |

Пока меню закреплено, ввод не доходит до игры; в режиме `TAB` перехватывается
только мышь.

## Сборка

Целевая платформа зафиксирована в [.cargo/config.toml](.cargo/config.toml), так
что достаточно:

```bash
cargo build --release
```

Результат — `target/i686-pc-windows-msvc/release/BTamaCheat.dll`.

Тесты (разбор сигнатур, поиск по маске, распаковка цвета, проверка рамок и
прогон самого ассемблерного детура):

```bash
cargo test
```

Если 32-битный тулчейн ещё не установлен:

```bash
rustup target add i686-pc-windows-msvc
```

## Запуск

DLL инжектируется любым инжектором в процесс игры. Сам инжектор в репозиторий
не входит и намеренно исключён в `.gitignore`.

## Диагностика

Консоли у инжектированной DLL нет, поэтому лог пишется сразу в два места:

- `OutputDebugStringW` — видно в DebugView или подключённом отладчике;
- `%TEMP%\BTamaCheat.log` — переживает падение игры.

Путь к файлу показан в самом меню, пока хук не установлен.

## Устройство

| Модуль | Ответственность |
|---|---|
| [`src/scan.rs`](src/scan.rs) | поиск сигнатуры в исполняемой памяти |
| [`src/hook.rs`](src/hook.rs) | детур `SetPosition`, сбор указателей на объекты |
| [`src/mem.rs`](src/mem.rs) | проверяемый доступ к памяти игры |
| [`src/offsets.rs`](src/offsets.rs) | смещения полей |
| [`src/game.rs`](src/game.rs) | разбор игровых объектов |
| [`src/overlay.rs`](src/overlay.rs) | интерфейс и применение читов |
| [`src/log.rs`](src/log.rs) | диагностика |

Каталог [`re/`](re/) — дампы структур из Cheat Engine, источник всех смещений
в `offsets.rs`. При обновлении игры сверяться нужно с ними.

## Известные ограничения

- **Камера.** Мировые координаты переводятся в экранные вручную заданными
  масштабом и сдвигом: полей камеры в снятых дампах нет. Пока они не найдены,
  рамки ESP выравниваются ползунками `Zoom` / `Cam X` / `Cam Y`.
- **Классы ловушек.** У базового `Trap` по смещениям `0xA4` и `0xAC` лежит
  прямоугольник коллизии, а у `BoomTrap` — `Speed` и `m_CanTrigger`. Имён
  классов в рантайме нет, поэтому класс помечается вручную в разделе
  «Классы»; без пометки эти поля не показываются и не пишутся.
- **Сетевая игра.** Правка параметров и общих объектов расходится с состоянием
  на стороне второго игрока.
